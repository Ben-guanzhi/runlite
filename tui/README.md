# Runlite TUI - 文本用户界面

runlite 的终端版本，替代原有的 GUI。基于 Bubbletea 框架构建。

## 功能特性

- **项目列表管理**: 查看已注册的项目及其运行状态
- **启动/停止控制**: 启动、重启、停止项目
- **实时日志**: 查看项目运行日志，支持跟随模式
- **项目添加移除**: 添加新项目到管理列表，从列表中移除项目
- **状态监控**: 实时监控 daemon 连接状态和项目状态

## 快捷键操作

| 按键 | 功能 | 说明 |
|------|------|------|
| ↑ / ↓ | 导航 | 在项目列表中上下移动 |
| / | 搜索 | 按名称过滤项目列表（esc 退出过滤） |
| 空格 | 启动 | 启动当前选中的项目 |
| s | 停止 | 停止当前选中的项目 |
| r | 重启 | 重启当前选中的项目 |
| del | 移除 | 删除当前选中的项目（y 确认 / n 取消） |
| a | 添加 | 打开添加项目表单 |
| ctrl+d | 目录选择 | 表单内打开原生文件夹选择对话框 |
| t | 标签页 | 切换右侧面板（日志/配置/高级） |
| A / S | 批量操作 | 批量启动全部 / 批量停止全部 |
| tab | 切换 | 在输入框之间切换焦点 |
| esc | 取消 | 退出表单模式或帮助视图 |
| q | 退出 | 退出程序 |
| ? | 帮助 | 显示操作帮助 |

按键布局可在 `~/.runlite/tui_keys.json` 中自定义，例如：

```json
{ "stop": ["x"], "quit": ["ctrl+q"] }
```

## 使用方法

### 构建

```bash
cd tui
go build -o runlite-tui
```

### 运行

```bash
./runlite-tui
```

确保 daemon 正在运行，如果没有，TUI 会自动尝试启动它。

## 与 CLI 的区别

| 特性 | CLI | TUI |
|------|-----|-----|
| 交互方式 | 命令行参数 | 交互式界面 |
| 日志查看 | 需指定 `-f` 参数 | 自动轮询更新 |
| 状态显示 | 一次性输出 | 实时更新 |
| 学习成本 | 需记忆命令 | 直观可视化 |
| 适用场景 | 脚本化/远程 | 本地开发 |

## 技术实现

- 使用 `bubbletea` 作为核心框架
- `bubbles` 组件库提供标准 UI 组件
- `lipgloss` 处理样式和布局
- 独立 module 隔离依赖，不影响 CLI
- 与 daemon 通信采用相同的 HTTP 客户端

## 模块结构

```
tui/
├── main.go              # 程序入口
├── model.go             # 主逻辑和状态管理（含帮助视图）
├── optimizations.go     # 摘要/裁剪等辅助函数
├── model_test.go        # 状态机与配置单元测试

├── config_e2e_test.go   # tui_config.json 端到端验证（go test -tags e2e）
├── testing_framework.go # 实验代码（//go:build ignore，不参与构建）
└── go.mod               # 模块定义
```

## 配置选项

- **按键布局**: `~/.runlite/tui_keys.json`（JSON，按动作覆盖默认按键）
- **刷新间隔 / 主题 / 默认端口**: `~/.runlite/tui_config.json`

```json
{
  "log_poll_ms": 700,
  "project_poll_ms": 1500,
  "default_port": 8080,
  "theme": { "running": "42", "stopped": "214", "failed": "196", "idle": "241", "ts": "241", "err": "196" }
}
```

- `log_poll_ms` / `project_poll_ms`: 日志与项目轮询间隔（毫秒），分别钳制在 200–10000 / 500–60000
- `default_port`: 添加项目时使用的端口（0 或缺省 = 自动检测）
- `theme`: 状态颜色，取值为 256 色号或 `#rrggbb`；未填的项保留默认色

## 已知限制

1. **窗口大小**: 需要至少 80x24 的终端
2. **批量操作**: A/S 对每个项目串行调用 daemon 接口，项目多时耗时线性增长
3. **日志缓冲区**: 有最大字节数限制
4. **目录对话框**: 依赖 PowerShell COM，仅 Windows 可用（可手动输入路径兜底）

## 与原有 GUI 对比

| 对比项 | GUI (Fyne) | TUI (Bubbletea) |
|--------|------------|-----------------|
| 依赖 | CGO, 图形库 | 纯 Go，无外部依赖 |
| 安装 | 复杂 | 简单 (`go get`) |
| 性能 | 较重 | 轻量快速 |
| 部署 | 需要图形环境 | 任意 SSH/Terminal |
| 跨平台 | Windows/macOS/Linux | 同左 |
| 内存占用 | ~50-100MB | ~10-20MB |
