# Runlite TUI - 终端用户界面指南

## 🎯 概述

runlite TUI 是一个基于 `Bubbletea` 的终端用户界面，用于替代原有的 Fyne GUI。它提供更轻量的交互方式，适合 SSH 远程环境或不喜欢图形界面的用户。

## ✨ 主要功能

- **项目管理**: 查看、添加和移除项目
- **启动控制**: 启动、重启和停止项目
- **实时日志**: 自动轮询并显示项目日志
- **状态监控**: 实时监控 daemon 连接和项目状态

## 🚀 快速开始

### 1. 构建 TUI

```bash
cd tui
go build -o runlite-tui
```

### 2. 运行

```bash
./runlite-tui
```

确保 daemon 正在运行（TUI 会自动尝试启动它）。

## ⌨️ 快捷键操作

| 按键 | 功能 | 说明 |
|------|------|------|
| ↑ / ↓ | 导航列表 | 在项目列表中上下移动 |
| **空格** | 启动项目 | 启动当前选中的项目 |
| r | 重启项目 | 重启当前选中的项目 |
| del | 移除项目 | 删除选中的项目（需要确认） |
| a | 添加项目 | 打开添加项目表单 |
| tab | 切换焦点 | 在输入框之间循环切换 |
| esc | 取消/退出 | 退出表单模式或帮助视图 |
| q | 退出程序 | 完全退出 TUI |
| ? | 帮助 | 显示操作帮助信息 |

## 📖 详细使用说明

### 添加新项目

1. 在主界面按 **a** 键
2. 使用 **Tab** 键在不同字段间切换
3. 填写目录路径（必填）
4. 可选填写项目名称和自定义命令
5. 按 **Enter** 提交
6. 按 **Esc** 取消

### 管理项目

- **选择项目**: 使用 ↑↓ 箭头键导航列表
- **查看详情**: 右侧区域显示选中项目的详细信息
- **启动项目**: 选中后按空格键
- **重启项目**: 选中后按 r 键
- **移除项目**: 选中后按 Delete 键，然后输入 y 确认

### 查看日志

日志面板位于右下角：
- 自动刷新（默认 0.7 秒间隔）
- 错误行前缀显示 `!` 标记
- 时间戳格式：`HH:MM:SS`
- 受内存限制（最大 512KB）

## 🆚 TUI vs GUI 对比

| 特性 | TUI (本版本) | GUI (Fyne) |
|------|-------------|------------|
| **依赖** | 纯 Go 模块 | CGO + 图形库 |
| **安装** | `go get` 即可 | 复杂依赖 |
| **性能** | 轻量 (~10-20MB) | 较重 (~50-100MB) |
| **部署** | 任意终端 | 需图形环境 |
| **SSH 支持** | ✅ 完美支持 | ❌ 不支持 |
| **响应速度** | 瞬间启动 | 需数秒加载 |
| **学习曲线** | 低（记忆快捷键） | 低（所见即所得） |

## 🔧 技术细节

### 架构设计

- **单线程模型**: 使用 Bubbletea 的命令查询分离子模式 (CQRS)
- **无状态**: 所有数据从 daemon API 获取
- **独立模块**: `tui/` 作为独立 Go 模块，不污染 CLI

### 轮询机制

```
项目列表刷新间隔：1.5 秒
日志刷新间隔：0.7 秒
日志保留上限：4000 行 或 512KB
```

### 线程安全

由于 Bubbletea 的运行时模型是单线程的，大部分锁已优化掉。仅日志访问保留必要的同步保护。

## 💡 高级用法

### 后台运行（推荐配合 tmux/screen）

```bash
tmux new -s runlite
./runlite-tui
# Ctrl+B, D  detach
```

### 窗口大小调整

TUI 会自动适应终端大小，建议最小分辨率：
- **宽度**: 80 字符
- **高度**: 24 字符

### 自定义主题

目前尚未支持，未来可能通过配置文件实现。

## ⚠️ 已知限制

1. **目录选择**: 暂不支持文件对话框，需手动输入路径
2. **并发操作**: 某些操作会阻塞其他操作约 1-2 秒
3. **输入验证**: 目录有效性依赖后端检查
4. **批量操作**: 仅支持单个项目操作
5. **搜索过滤**: 暂无项目搜索功能

## 📝 故障排除

### 常见问题

**Q: 无法连接到 daemon**
- A: 确认 `runlite.exe` 在 PATH 中或同目录下
- A: 手动运行 `runlite daemon start`

**Q: 终端显示异常**
- A: 尝试关闭色彩支持：`less -R ./tui/runlite-tui`
- A: 确保终端支持 ANSI 转义序列

**Q: 日志显示不完整**
- A: 这是正常的，有内存限制保护
- A: 可使用 CLI 查看更多历史：`runlite logs <项目>`

**Q: 输入无响应**
- A: 可能在等待其他操作完成，稍等片刻
- A: 检查是否有未确认的对话框
